# Evidencias de los agentes automatizados

Registro de ejecuciones **reales** de los tres agentes de CivicMesh
(Documentador, Revisor de bugs, Revisor de Pull Requests). Este documento
se completa a medida que los agentes corren de verdad en el repositorio
(GitHub Actions ya ejecutado, issue o comentario real creado) — no antes.

No contiene todavía ninguna fila: los workflows (`agent-documenter.yml`,
`agent-bug-reviewer.yml`, `agent-pr-reviewer.yml`) recién se incorporan en
esta rama y no se ejecutaron aún contra el repositorio real. No se inventan
IDs de issues/PRs ni URLs — cada fila debe corresponder a algo verificable
en GitHub.

La entrega final del laboratorio requiere al menos **dos evidencias reales
por agente**.

| Agente | Tipo | Evidencia | Enlace |
| ------ | ---- | --------- | ------ |
| _(pendiente)_ | | | |

## Cómo completar una fila

- **Agente**: `documenter`, `bug_reviewer` o `pr_reviewer`.
- **Tipo**: `issue creado`, `comentario en PR`, `ejecución manual (workflow_dispatch)`, etc.
- **Evidencia**: descripción breve de lo que se generó.
- **Enlace**: URL real al issue/comentario/run de GitHub Actions
  correspondiente. Nunca completar con una URL inventada o de ejemplo.
